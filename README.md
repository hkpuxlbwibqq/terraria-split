## Overview

Terraria Split adds genuine split-screen cooperative multiplayer to Terraria, rendering a separate viewport for each local player simultaneously within a single game window. Up to four players share one keyboard/mouse and gamepad setup or use individual controllers, making couch co-op Terraria sessions possible for the first time.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **Terraria Split** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **True Split-Screen** | Separate viewports per player rendered simultaneously in one window |
| **Up to 4 Players** | Supports up to four local players in any split-screen layout |
| **Controller Support** | Full gamepad support for comfortable couch co-op sessions |
| **Shared World** | All players inhabit the same Terraria world simultaneously |
